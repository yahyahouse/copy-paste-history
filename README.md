# Clip History

A lightweight clipboard history app for macOS that lives in your menu bar. Native Swift + AppKit, no dependencies.

## Install with Homebrew

```bash
brew tap yahyahouse/clip-history https://github.com/yahyahouse/copy-paste-history
brew install --cask clip-history
```

That's it, no Gatekeeper warning to click through. The app keeps itself up to date after that.

To uninstall:

```bash
brew uninstall --cask clip-history          # keep your history
brew uninstall --cask --zap clip-history    # also delete your history
```

## Download

Or grab the latest `.dmg` from [Releases](https://github.com/yahyahouse/copy-paste-history/releases/latest), open it, and drag Clip History into Applications.

The app isn't notarized by Apple yet, so macOS will warn you the first time you open it. Run this once:

```bash
xattr -dr com.apple.quarantine /Applications/ClipHistory.app
```

Or right-click the app → Open → Open.

Requires macOS 13 or later. Runs on both Apple Silicon and Intel.

## Features

• Windows-style popup panel (like Win+V), opens at your cursor with Cmd+Shift+V
• Click an item or press Enter to paste it right away
• Pin important items so they never get removed
• Delete button on every item, plus "Clear all" for everything that isn't pinned
• Keyboard navigation: ↑↓ to select, 1–9 for quick pick, Delete to remove, Esc to close
• Keeps up to 10 items, up to 7 of them pinned. The oldest unpinned item is removed when you copy something new
• Ignores text copied from password managers
• History is saved to `~/Library/Application Support/ClipHistory/history.json`, so it survives restarts
• Optional "Open at Login"
• Follows your macOS language: Indonesian if your Mac is set to Indonesian, English otherwise

## Auto-update

The app checks GitHub for a new release when it starts and every 6 hours after that. When a new version is out, it downloads the DMG, replaces itself, and relaunches. You can also check manually from the menu with "Check for Updates". The app needs to be in the Applications folder for this to work.

## Auto-paste

Click "Enable Auto-Paste…" in the menu, then allow Clip History in System Settings → Privacy & Security → Accessibility (called "Device Control and Data Access" on newer macOS). Official releases are signed with the same certificate, so this permission carries over between updates.

If paste stops working after installing a build from somewhere else, reset the permission and grant it again:

```bash
tccutil reset Accessibility com.yahyawijaya.cliphistory
```

## Build from source

```bash
xcode-select --install   # if you don't have it yet
./build.sh               # outputs ClipHistory.app
./make-dmg.sh 1.0.0      # outputs ClipHistory-1.0.0.dmg
```

The app icon is generated by `icon/make_icon.py` (needs Pillow) and converted to `.icns` during the build.

## Releasing a new version

Create a new release on GitHub with a tag like `v1.6.0`, or run:

```bash
git tag v1.6.0
git push origin v1.6.0
```

GitHub Actions builds the DMG, signs it, and attaches it to the release. Installed copies pick it up through auto-update.

Signing uses two repository secrets: `SIGNING_CERT_P12` (base64 of the .p12) and `SIGNING_CERT_PASSWORD`. Without them the build falls back to ad-hoc signing.

## Configuration

Tweak the constants at the top of `main.swift`: number of items, number of pins, and the hotkey.
